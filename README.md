# Maritime Docs: корпус документов по морской перевозке грузов

Репозиторий содержит нормативные и справочные материалы для учебной и исследовательской работы по безопасности морской перевозки грузов.

## С чего начать

1. **[CATALOG.md](CATALOG.md)** — тематический каталог документов, известные дубликаты, неоднозначные названия и приоритетные проверки.
2. **[AGENT_GUIDE.md](AGENT_GUIDE.md)** — правила поиска, ответа и цитирования для ИИ-агента, работающего с этим корпусом.
3. **[DEMO_SCRIPT.md](DEMO_SCRIPT.md)** — сценарий демонстрации агента и контрольные вопросы.
4. **[texts/](texts/)** — текстовый слой для поиска.
5. **Нормативные документы для Исследовательской работы/** — исходные PDF и другие материалы.

## Для чего предназначен корпус

- находить положения документов по теме груза и операции;
- готовить ответы с точными ссылками на документ, пункт и страницу;
- сопоставлять требования нескольких источников;
- выявлять пробелы, неоднозначные редакции и вопросы, требующие проверки по официальному источнику.

## Важные ограничения

- Наличие файла в репозитории не означает, что документ действует или применим к конкретной ситуации.
- OCR и извлечённый текст могут содержать ошибки, особенно в таблицах, формулах, числах и сканах.
- Для дословной цитаты и критически важных значений нужно сверять текст с исходным PDF.
- Если подтверждение не найдено, нельзя делать вывод, что требования не существует.
- Международные кодексы и иные документы следует проверять по официальному источнику, с учётом редакции, поправок и применимости.

## Текущее состояние

Корпус находится в стадии инвентаризации и контроля качества. Статус проверки отдельных документов описан в [CATALOG.md](CATALOG.md) и `texts/extraction_report.txt`, если этот отчёт доступен в текущей версии репозитория.

## Основной принцип

**Не просто ответить, а показать, на каком источнике и конкретном фрагменте основан ответ.**
