# Maritime Docs: корпус документов по морской перевозке грузов

Репозиторий содержит нормативные и справочные материалы для учебной и исследовательской работы по безопасности морской перевозки грузов.

## С чего начать
1. **[CATALOG.md](CATALOG.md)** — тематический каталог, дубликаты, неоднозначные названия и приоритетные проверки.
2. **[AGENT_GUIDE.md](AGENT_GUIDE.md)** — алгоритм поиска, проверки полноты, веб-проверки и цитирования.
3. **[AGENT_PROMPT.md](AGENT_PROMPT.md)** — системные инструкции; их нужно отдельно перенести в настройки используемого ChatGPT Project или другой платформы.
4. **[AUDIT_PLAN.md](AUDIT_PLAN.md)** — план аудита состава корпуса, качества OCR и пробелов в источниках.
5. **[AUDIT_REPORT.md](AUDIT_REPORT.md)** — предварительные результаты первой проверки; аудит не завершён.
6. **[GAP_ANALYSIS.md](GAP_ANALYSIS.md)** — подтверждённые приоритетные риски и пробелы.
7. **[DEMO_SCRIPT.md](DEMO_SCRIPT.md)** — сценарий демонстрации и контрольные вопросы.
8. **texts/** — текстовый слой для поиска.
9. **Нормативные документы для Исследовательской работы/** — исходные PDF и другие материалы.

## Для чего предназначен корпус
- находить положения документов по теме груза и операции;
- готовить ответы со ссылками на документ, пункт и страницу;
- сопоставлять требования нескольких источников;
- выявлять пробелы, неоднозначные редакции и вопросы для проверки по официальному источнику.

## Важные ограничения
- Наличие файла не означает, что документ действует или применим к конкретной ситуации.
- OCR может содержать ошибки, особенно в таблицах, формулах, числах и сканах.
- Для цитат и критически важных значений нужно сверять исходный PDF.
- Если подтверждение не найдено, нельзя заключать, что требования не существует.
- Интернет-поиск должен реально выполняться доступным инструментом. Если инструмент недоступен, агент обязан сказать об этом, а не имитировать проверку.

## Текущее состояние
Корпус находится в стадии инвентаризации и контроля качества. Каталог и план аудита не доказывают завершение проверки. Статусы отдельных документов описаны в CATALOG.md и texts/extraction_report.txt, если отчёт доступен в текущей версии.

## Основной принцип
**Не просто ответить, а показать, на каком источнике и конкретном фрагменте основан ответ.**
